Read the same cell in three ways

Select black triangles, inspect their signed sparse matrix, and compare the resulting boundary permutation with the plabic ladder. The atlas has 850 triangle-tiles across 14 families, a subfamily of the positroid tiles of Parisi, Sherman-Bennett and Williams, The m=2 amplituhedron and the hypersimplex (arXiv:2104.08254; bicolored triangulations in Definition 4.1, tiles in Theorem 4.25), called PSW below. It is not one simultaneous tiling of the amplituhedron.

1. Choose a tile

The tile dropdown, swap-graph nodes, and neighbor buttons select the same object. An edge joins two tiles of type k that share k−1 black triangles and whose remaining triangles share two vertices. Its edges are not certified geometric facet adjacencies.

2. Follow the strands

The lower-right ladder draws each strand as a cubic Bézier path. Click a strand, or select a start in Highlight trip, to see its start → end mapping. Enter or Space also selects a focused strand. The top labels name legs; the colored bottom labels identify the starting strand at its exit.

Face labels and bridge α labels have separate controls. Export SVG saves the current view. These α indices come from the bridge order; they are not the α/β/γ values in the matrix.

The top-left PSW overlay still shows endpoint arrows, not routed ladder paths. Its colors are aligned with the lower-right strand palette.

3. Change positive weights

Use decimals or fractions, then recompute. Positive row rescaling changes all maximal minors by a common scale and leaves the plane unchanged. The plabic drawing names the cell, so it is unchanged by these positive weight variations. No bridge-weight conversion is claimed.

What the checks establish

Every cubic control point was compared with an earlier Python renderer of the same ladders. Endpoint checks agree with each tile’s permutation. Face labels reproduce a simplified combinatorial recursion and belong to the recorded basis support. These finite checks do not certify that algorithm for arbitrary cells, a Postnikov-move path, or a geometric tiling.

Snapshot versus live Python

The same curves are bundled as compact JSON so the atlas remains readable while Python loads. Once the Pyodide worker is available, it computes the geometry locally from symbolic inputs. The interface labels which mode is being displayed.
