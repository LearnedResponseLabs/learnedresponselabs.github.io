Reading the BCFW tile explorer

Open the explorer →

Choose one of nine families A(n,k,4), then select a tile. Here n counts boundary markers, k counts chords, and m = 4 fixes the amplituhedron construction. The catalogue contains 385 diagrams. Each indexes a standard BCFW cell whose image is a tile, a region of the amplituhedron.

A flip changes the diagram

Each node on the left is a tile indexed by a noncrossing chord diagram. A chord (a,b,c,d) has its start on the segment (a,b) and its end on the segment (c,d); here b = a+1 and d = c+1, and no chord ends after marker n−1. Two nodes are joined when exactly one chord is replaced. This defines the explorer’s flip relation; an edge does not assert a single cluster mutation between tiles.

The plabic graph is a planar bicolored graph describing the selected cell. The decorated permutation records its boundary combinatorics; support labels list the nonzero Plücker coordinates of the realization in Gr(k,n). The cell realization matrix describes points using positive parameters. These data and images stay fixed while you mutate a seed.

A mutation changes the seed within one tile

A seed consists of a collection of variables and a quiver encoding exchange relations. At a mutable variable x, mutation replaces x by (M₊ + M₋)/x, where the two monomials use incoming and outgoing arrows with their multiplicities, then updates the arrows. Frozen variables never mutate. Undo and redo replay the recorded mutation path.

The quiver draws each distinct domino variable once. If a child chord starts one segment after its immediate containing chord and has the same end segment, its β variable equals that chord’s α variable. The single vertex carries both names. The arrows use the exponents of the source’s exchange relations. Frozen–frozen arrows are omitted. Additional frozen variables of the full extended cluster are outside this view.

Names remain attached to their initial positions after mutation; symbolic expressions are not computed. The cell realization matrix on the left is unrelated to the auxiliary C-matrix used for search.

What the type label checks

The type label describes the principal quiver on distinct mutable variables. Products use x and repeated components use ^: A1xD5 means two components, and A1^2 means two copies of A1. A, D and E are finite Dynkin types; rigid means no mutable variables and one cluster. The finite cluster count is computed from the type formula.

The evidence text distinguishes an acyclic positive-definite Cartan certificate, an acyclic non-positive Cartan certificate, an escalated Cartan search, and a source theorem with a quiver-isomorphism check. The constructor’s non-finite labels are retained: affine~8 denotes its rank-eight affine certificate, while Gr48-infinite identifies the Gr(4,8) case. The labels do not classify every frozen variable of the full extended cluster.

Node shapes show the highest E, then D, then A component; rigid nodes are circles and non-finite nodes are diamonds. The type checks are supplied with the data, not recomputed by the browser. A numerical search or a working interface is not a mathematical proof.

What the bounded graph identifies

The right graph tracks the principal exchange matrix together with an auxiliary principal-coefficient C-matrix, initially the identity. Its identity rule groups states by the unordered rows of the C-matrix. It does not merge states merely because their arrows match. Edges record mutations; clicking a node replays one shortest discovered path.

For each finite type in the catalogue, a separate exhaustive seed search has been compared with the type formula. A completed browser search also compares its state count with that formula. The graph is called a C-matrix seed graph to make its computational identity explicit; this guide makes no general uniqueness claim about C-vectors.

The default cap is 96 states and the largest selectable cap is 512. The search stops adding states at the cap; it does not count further states without drawing them. It completes edges between already discovered nodes and reports transitions leaving the displayed set. Even a capped finite search can therefore remain incomplete. Larger finite types, including E7 with 4160 clusters, cannot fit in this view. A matrix-size stop is also reported. Neither kind of stop implies infinite type. A mutation path can continue outside the displayed search, with that fact stated in the status.

Source and computation

The construction follows Definition 7.8 and Definitions 10.4 and 10.8, Remark 10.5 and Lemma 10.13 of Cluster algebras and tilings for the m = 4 amplituhedron. Version 3 and PDF.

Initial seeds and tile geometry are supplied as static files. Live calculations load a Python runtime and run locally in a background browser thread.
