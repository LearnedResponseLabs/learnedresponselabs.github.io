05 / move inside this tile

A positive matrix → a point in the chamber

Unit-weight snapshot

Each length-L gap run supplies a Vandermonde block in Gr(L,L+1). Change its positive column weights, form Y = CZ, and read Y⊥ ∝ (1,x₁,…,xₖ). The resulting point stays in this chamber. Loop-column weights have no effect.

Python is needed for non-unit weights.

Advanced: change the ordered moment-curve parameters

Replace t₁,…,tₙ with positive, strictly increasing rational numbers. This recomputes the geometry and projections but keeps the gap labels and facet adjacency. Collisions and arbitrary external Z are outside this viewer.
